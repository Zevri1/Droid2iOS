# Security Policy

## Scope

This repository is a research website and documentation project. It does not currently distribute device firmware, boot images, installers, or executable system components.

## Reporting a concern

Please do not publish secrets, access tokens, signing material, personal data, or exploitable details in a public issue. For a security concern affecting this repository or its deployment, contact the repository maintainer privately through GitHub's available contact options.

Include the affected component, impact, reproduction conditions, and a suggested mitigation where possible.

## Safe research

- Do not test on devices or accounts you do not own or have permission to use.
- Do not publish private keys, credentials, or personal device data.
- Do not redistribute proprietary firmware or copyrighted system images.
