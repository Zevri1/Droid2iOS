# Glossary

| Term | Meaning |
|---|---|
| ARM64 / AArch64 | 64-bit ARM instruction-set architecture. |
| Darwin | Apple's Unix-based operating-system foundation. |
| XNU | The kernel used by Darwin; its name reflects X is Not Unix. |
| Mach | The microkernel-derived component underlying parts of XNU. |
| BSD | The Unix-derived subsystem integrated into XNU. |
| Device tree | A structured description of hardware devices and their connections. |
| Boot chain | The sequence of firmware and software stages that starts a system. |
| SoC | System-on-chip; integrates CPU and other platform components. |
| Driver | Software that controls or exposes a hardware device to the operating system. |
| Userspace | Processes and services running outside the kernel. |
| Proof of concept | A limited experiment demonstrating one specific technical claim. |
| Bring-up | Initial work required to make an operating system recognize and initialize a platform. |
